# Планировщик задач (TODO-лист)

Проект реализует функциональность планировщика задач с веб-интерфейсом и REST API серверной частью на Go.

## Основные функции

- Добавление новых задач с различными параметрами
- Удаление существующих задач
- Получение списка всех задач
- Редактирование параметров задач
- Поддержка повторяющихся задач (ежедневные, еженедельные, ежегодные)
- Автоматический расчет следующих дат для повторяющихся задач

## Технологии

- **Backend**: Go (чистый HTTP, без фреймворков)
- **Frontend**: HTML, CSS, JavaScript (чистый JS без фреймворков)
- **База данных**: SQLite
- **API**: RESTful

## Инструкция по запуску кода локально

Клонируйте репозиторий:
> git clone https://github.com/alyunov/go_yap_final_prj.git
> cd go_yap_final_prj

Соберите проект в исполняемый файл todo:
> go build -o todo

Запустите приложение:
> ./todo

Откройте веб-интерфейс в браузере:
> http://localhost:7540
